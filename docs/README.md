# Presentation

`Ikenna_Odoh_NovaWallet_Case_Study.pptx` is the 10-minute case-study deck, with speaker notes on every slide.

It is generated by `build-deck.js`. To rebuild it, install the dependencies and run the script:

```bash
npm install pptxgenjs react-icons react react-dom sharp
node build-deck.js Ikenna_Odoh_NovaWallet_Case_Study.pptx
```
